## Install vynq on Android

vynq is an early test version: end-to-end encrypted messages and calls between people you add by username. It hasn't had an independent security review yet.

**Needs:** Android 9 or newer on a 64-bit phone (almost every phone from 2019 on), and an email address for the sign-in code.

1. Download **`vynq-<version>.apk`** below on your phone.
2. Open it. Android asks to allow installs from your browser or file manager the first time: allow it, go back, and tap **Install**. (Some phones show a security scan or warning for apps from outside a store; that's expected for a direct download.)
3. Open vynq, enter your email, type the 6-digit code you receive, and pick a username.
4. Go to **Settings → Notifications** and work through the checklist so messages and calls reach you when vynq is in the background. Phones from Xiaomi, OPPO, realme, OnePlus, vivo, Huawei and Honor need the extra Autostart and battery settings listed there.

**Updates:** vynq shows a banner in Chats when a newer version is out. Download and install it the same way; your messages and account stay on the phone. If Android ever says the update "conflicts with an existing package", don't uninstall without first saving your recovery key (Settings → Message history), or your message history on that phone is lost.

**Check the download (optional):** the `.sha256` file next to the APK holds its SHA-256 checksum.
